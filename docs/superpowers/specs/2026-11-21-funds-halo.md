# 资金光环驾驶舱设计

## 目标

将家庭资金总览改为以真实资产结构驱动的浅色资金光环驾驶舱。保留当前极光玻璃配色、全部类别占比合计 100%、罗盘聚焦与下方筛选联动，以及默认只统计存续中资产的口径。

## 页面结构

- 首屏中心为资产光环，中心明确显示当前筛选金额及口径。外环用所有有金额的类别占比构成，点击类别只弱化其他类别，不将其移除。
- 类别微型面板围绕光环布局，列出类别名称与占比；手机端改为光环下方的两列列表。
- 首屏两侧使用真实数据展示非储蓄、储蓄、记录数、成员数和未来半年到期额。缺失数据不填虚构数字。
- 下方资产透视、到期计划、趋势和成员区延续相同的颜色与节奏；图表保持清晰、可读，初次进入就可见。

## 动效与交互

- 光环的背景光束与环线采用舒缓、非同步的脉冲节奏；持续亮度低于正文和图表，不加入背景音乐或自动运镜。
- 点击类别时先有一道清晰的光命中罗盘旁的旋转光点，光点飞向罗盘中心并在途中变成金币，中心金额随飞行同步变化；金币再沿罗盘中心竖直向下飞，旋转放大后以细光线直射页面中实际存在的每张图表，以及到期计划右侧明细表。新增图表自动加入落点；视野在光线散开前调整到图表区域。光线消失后，各卡片由中间展开并显示筛选结果，随后返回页顶。再次点击当前类别时，金币显示“全部资产 100%”。
- 屏幕较小或系统设置减少动态效果时，减少光束数量并停止持续动画；筛选功能仍可用。

## 数据与许可

- 总额、类别、成员和到期指标均来自现有汇总接口。默认 ACTIVE；选择历史状态时继续标明其为记录金额合计。
- 借鉴 HaloFlux 的环形层次和节拍感，独立实现资金主题的结构与样式，不复制其代码或媒体。HaloFlux 原项目按 PolyForm Noncommercial 1.0.0 授权。
